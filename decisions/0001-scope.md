# ADR 0001 — Scope dan arsitektur pengetahuan

Status: diterapkan untuk release ini. Tanggal: 8 Oktober 2026.

Konteks: pemilik meminta repository portofolio-web untuk knowledge base lengkap mengenai portofolio frontend yang berkualitas tinggi, motion/design/coding kuat, gratis dan backend ditunda.

Keputusan: 32 modul M01–M32 pada 8 bidang; Markdown, JSON catalog/graph dan contoh native HTML/CSS/JS. Private repository sebagai default pembuatan; tidak mengubah site atau visibility. Contoh fiktif dibedakan dari portfolio pemilik. Tidak ada package production wajib, third-party trackers atau backend.

Alternatif: daftar topik saja tidak cukup operasional; framework wajib membatasi fleksibilitas; seluruh materi dimuat setiap tugas meningkatkan noise. Modul terhubung dan retrieval terarah dipilih.

Konsekuensi: materi dapat dipakai bertahap, dengan perluasan cabang advanced bila proyek membutuhkannya. Source freshness, browser QA dan performance tetap membutuhkan pemeriksaan saat implementation. Publishing Pages gratis kelak perlu keputusan repository/visibility yang sesuai.
