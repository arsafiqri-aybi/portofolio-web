# Template kerja

Template adalah formulir untuk diisi dengan fakta proyek, bukan dokumen final atau hasil uji.

- [Brief](brief.md)
- [Case study](case-study.md)
- [Motion spec](motion-spec.md)
- [Component contract](component-contract.md)
- [ADR](adr.md)
- [Test report](test-report.md)
- [Performance report](performance-report.md)
- [Asset manifest](asset-manifest.csv)
- [Content schema](project.schema.json)

Nilai kosong harus dilengkapi atau ditandai belum tersedia; jangan mengisi hasil fiktif sebagai fakta. Schema dapat dipakai alat JSON Schema yang sesuai, tetapi tidak menggantikan review editorial.
