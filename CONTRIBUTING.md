# Memperbarui knowledge base

1. Tetapkan masalah dan modul induk; baca materi aktual.
2. Tambahkan prinsip, metode, contoh, failure, verification dan sumber.
3. Bedakan standar, panduan, hasil studi dan keputusan proyek.
4. Catat akses sumber serta tanggal/version; tidak perlu mengaudit ulang yang tidak relevan.
5. Perbarui graph/topic catalog ketika struktur berubah.
6. Jalankan validator dan checks terdampak; simpan hasil jujur.
7. Commit perubahan koheren dan tulis changelog.

Jangan memasukkan token, data klien, testimonial palsu, placeholder yang menyamar menjadi hasil, atau status test tanpa pelaksanaan. Tidak ada lisensi distribusi publik yang ditetapkan otomatis; repository private ini tidak memindahkan hak sumber pihak ketiga.
