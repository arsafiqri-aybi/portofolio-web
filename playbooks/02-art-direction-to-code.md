# Playbook 02 — Dari arah artistik ke kode

1. Tulis karakter dan fungsi: contoh “editorial, teliti, fokus karya”. Terjemahkan tiap kata ke keputusan yang terlihat.
2. Pilih referensi dengan alasan: typography, rhythm, assets, motion. Jangan menyalin identitas atau mengambil aset tanpa izin.
3. Susun token peran, grid, type roles, palette dan image treatment.
4. Terapkan pada dua template dengan konten panjang dan nyata. Hero kosong tidak membuktikan sistem.
5. Buat specimen komponen/state. Link/button tetap berbeda semantik meski style serupa.
6. Implementasikan token CSS dan aturan responsive. Review visual dengan browser, bukan hanya kode.
7. Tambahkan motion vocabulary dengan reduced variant. Uji continuity dan interruption.
8. QA alignment, rhythm, hierarchy, crop dan focus pada layar sempit/lebar.

## Diagnosis dominan

Jika terasa generik, cari keputusan yang tidak berakar pada karya/identitas. Jika terasa kacau, cari terlalu banyak penekanan. Jika terasa lemah, cek ukuran/spacing/crop sebelum menambah gradient. Bila tampilan bagus tetapi tugas sulit, revisi hierarchy dan labels.

## Artefak

Art-direction spec, token list, component contract, asset provenance dan screenshot review. Review estetika AI bukan bukti selera manusia.
